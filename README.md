## 🌟 Overview

PixelForge AI is a modern web platform that empowers businesses to create professional-quality visual content using artificial intelligence. Whether you need product photography, marketing videos, or social media content, our AI handles it all with photorealistic quality.

### ✨ Key Features

- **AI Product Photography** - Generate photorealistic product images in any setting, style, or mood
- **Marketing Video Creation** - Create scroll-stopping video ads with AI-powered motion and effects
- **Brand Consistency** - Maintain your brand identity with custom style presets and color matching
- **Background Removal** - Instantly remove or replace backgrounds with photorealistic lighting
- **Lightning Fast** - Generate high-quality images in seconds, batch process entire catalogs
- **Multi-Platform Ready** - Auto-resize and optimize for Instagram, TikTok, Facebook, LinkedIn, and more
- **Commercial License** - Full commercial usage rights on all generated content
- **Unlimited Revisions** - Regenerate with different styles until it's perfect

## 🚀 Tech Stack

- **Frontend Framework**: React 18.2 with TypeScript
- **Styling**: Tailwind CSS 4.1 with custom gradients and glassmorphism effects
- **Animations**: Framer Motion 10.18 for smooth, performant animations
- **Icons**: Lucide React for beautiful, consistent iconography
- **Build Tool**: Vite 6.3 for lightning-fast development and builds
- **Routing**: React Router DOM 6.8 for navigation

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/pixelforge-ai.git

# Navigate to the project directory
cd pixelforge-ai

# Install dependencies
npm install

# Start the development server
npm run dev
```

The application will be available at `http://localhost:3000`

## 🏗️ Build for Production

```bash
# Build the project
npm run build

# Preview the production build
npm run preview
```

## 🔧 Configuration

### Environment Variables

Create a `.env` file in the root directory:

```env
VITE_API_URL=your_api_endpoint
VITE_API_KEY=your_api_key
```

### Customization

- **Colors**: Modify gradient colors in `src/index.css` and component files
- **Content**: Update text content in component files
- **Features**: Add/remove features in `FeaturesSection.tsx`
- **Pricing**: Adjust pricing tiers in `PricingSection.tsx`
